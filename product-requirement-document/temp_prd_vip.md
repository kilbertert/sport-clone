## 3. 需求概述

### 背景
当前平台面临三大核心挑战：一是销量场景失衡，线上增长承压，主站销量仅占整体 20%，随着线下业务扩张，线上占比预计进一步下降，流量与转化动力不足；二是会员运营粗放，权益感知弱化，现有会员权益趋同、触达低频，用户对会员身份的尊享感和获得感持续下滑；三是缺乏用户长期绑定机制，当前以单次交易为主，用户迁移成本低，线下业务便捷性可能进一步分流线上用户。

### 核心需求
推出年费会员体系，通过会员专享商品和分期优惠券两大核心权益，重新定义用户与平台的关系，将随机、低频的购物行为转化为有预期、有专属回报的长期互动。

### 预期效果
通过年费会员体系锁定高价值用户，稳定线上基本盘，提升会员活跃度与粘性，建立"预先付费、持续回馈"的契约式用户关系，预计年费会员用户年消费频次提升 30% 以上。

## 4. 需求背景与目标

### 4.1 背景

#### 1. 销量场景失衡，线上增长承压
- 主站销量仅占整体 20%，线上业务增长动力不足
- 线下业务持续扩张，线上销量占比预计进一步下降
- 线上流量获取成本高，转化效率有待提升
- 亟需通过会员体系锁定高价值用户，稳定线上基本盘

#### 2. 会员运营粗放，权益感知弱化
- 平台尚未对会员场景进行精细化分层与权益设计
- 现有会员权益趋同，缺乏差异化竞争力
- 会员触达频次低，用户对会员身份感知弱
- 尊享感和获得感持续下滑，会员活跃度降低

#### 3. 缺乏用户长期绑定机制
- 当前以单次交易为主，用户迁移成本低
- 线下业务便捷性可能进一步分流线上用户
- 缺少"预先付费、持续回馈"的契约式关系
- 用户生命周期价值（LTV）挖掘不足

### 4.2 目标

1. **业务目标**：年费会员渗透率达到线上活跃用户 10%，会员用户年消费频次提升 30%
2. **体验目标**：会员权益感知度达到 80% 以上，会员满意度达到 90%
3. **营收目标**：年费会员收入成为线上业务重要收入来源之一
4. **用户目标**：建立长期稳定的用户关系，降低用户流失率

## 6. 业务逻辑

### 6.1 业务流程图

```
用户浏览小程序/APP → 发现会员入口 → 查看会员权益
                              ↓
                      了解年费会员权益
                      （专享商品 + 分期优惠券）
                              ↓
                      购买年费会员
                              ↓
                      支付成功 → 获得会员身份
                              ↓
                      ┌─────────┴─────────┐
                      ↓                   ↓
              浏览会员专享商品      查看分期优惠券
                      ↓                   ↓
              享受会员专享价        下单使用优惠券
                      ↓                   ↓
              会员价购买商品        分期抵扣订单金额
```

### 6.2 流程说明

1. **会员发现**：用户在小程序/APP 首页、商品详情页等位置看到会员入口和权益提示
2. **权益了解**：用户进入会员中心，查看详细的年费会员权益说明
3. **会员购买**：用户选择购买年费会员，完成支付
4. **权益生效**：支付成功后立即获得会员身份，权益实时生效
5. **权益使用**：
   - **会员专享商品**：在商品详情页看到会员专享价，以优惠价格购买
   - **分期优惠券**：在购物车/结算页选择使用分期优惠券，抵扣订单金额
6. **会员续费**：会员到期前提醒续费，保持会员身份持续有效

## 7. 功能详细说明

### 7.1 年费会员购买与身份管理

#### 功能定位
年费会员的入口和购买流程，以及会员身份的管理和展示，是会员体系的核心入口。

#### 产品规则
1. 会员类型：仅支持年费会员，暂不支持月卡/季卡
2. 会员价格：建议定价 199 元/年（具体价格待运营确认）
3. 会员有效期：自购买之日起 365 天
4. 会员身份展示：在"我的"页面、商品详情页等位置展示会员标识
5. 续费规则：到期前 30 天开始提醒续费，支持提前续费

#### 字段定义

| 字段名 | 字段类型 | 是否必填 | 说明 |
|--------|----------|----------|------|
| member_id | string | 是 | 会员记录ID |
| user_id | string | 是 | 用户ID |
| member_type | string | 是 | 会员类型：annual（年费会员） |
| member_status | string | 是 | 会员状态：active（有效）/ expired（过期） |
| start_date | datetime | 是 | 会员开始时间 |
| end_date | datetime | 是 | 会员到期时间 |
| order_id | string | 是 | 会员购买订单ID |
| price | number | 是 | 会员购买价格 |

#### 业务定义
- **年费会员**：一次性购买，有效期 365 天的会员类型
- **会员身份**：购买成功后用户获得的特殊身份标识
- **会员到期**：超过 end_date 后会员状态自动变为 expired

#### 交互说明
- 会员入口位于"我的"页面显著位置
- 会员中心展示会员身份、到期时间、权益列表
- 非会员用户看到"立即开通"按钮，会员用户看到"已开通"状态
- 会员到期前 30 天在会员中心显示续费提醒

#### 异常处理
- **支付失败**：提示支付失败原因，支持重新支付
- **会员状态异常**：联系客服处理
- **重复购买**：提示"您已是年费会员，无需重复购买"

---

### 7.2 会员专享商品

#### 功能定位
为年费会员提供的专属优惠商品，是会员核心权益之一，体现会员尊享感。

#### 产品规则
1. 专享商品范围：精选爆款商品、新品首发、限量商品等
2. 专享价格：在普通售价基础上给予 5%-15% 的会员折扣
3. 商品标识：在商品列表、详情页等位置展示"会员专享"标识
4. 购买限制：仅限年费会员购买，非会员引导开通会员
5. 库存管理：专享商品库存与普通商品独立或共享（待确认）

#### 字段定义

| 字段名 | 字段类型 | 是否必填 | 说明 |
|--------|----------|----------|------|
| product_id | string | 是 | 商品ID |
| is_member_exclusive | boolean | 是 | 是否为会员专享商品 |
| member_price | number | 是 | 会员专享价 |
| original_price | number | 是 | 原始售价 |
| discount_rate | number | 是 | 折扣率，如 0.9 表示 9 折 |
| stock_type | string | 是 | 库存类型：independent（独立）/ shared（共享） |
| member_stock | number | 否 | 会员专享库存（独立库存时必填） |

#### 业务定义
- **会员专享商品**：仅限年费会员购买的特殊优惠商品
- **会员专享价**：低于普通售价的会员专属价格
- **折扣率计算**：member_price / original_price

#### 交互说明
- 商品列表中会员专享商品展示"会员专享"标签
- 商品详情页展示会员专享价，非会员看到"开通会员享优惠价"提示
- 非会员点击会员价区域，引导至会员购买页面
- 会员在商品详情页直接看到会员专享价，无需额外操作

#### 异常处理
- **专享商品库存不足**：提示"商品库存不足，去看看其他专享商品"
- **会员过期购买**：提示"您的会员已过期，续费后可继续享受会员价"
- **非会员尝试购买**：引导开通会员，不开放非会员购买入口

---

### 7.3 分期优惠券

#### 功能定位
年费会员获得的优惠券权益，分期发放，鼓励会员持续活跃消费。

#### 产品规则
1. 优惠券类型：满减券（如满 100 减 10、满 200 减 30）
2. 发放规则：购买年费会员后立即发放首期，之后按月发放
3. 发放周期：建议每月发放一次，共发放 12 期
4. 优惠券面额：建议每期包含多张不同面额优惠券（具体待运营确认）
5. 有效期：每张优惠券有效期 30 天（自然月）
6. 使用规则：可叠加使用，具体叠加规则待确认

#### 字段定义

| 字段名 | 字段类型 | 是否必填 | 说明 |
|--------|----------|----------|------|
| coupon_id | string | 是 | 优惠券ID |
| user_id | string | 是 | 用户ID |
| coupon_type | string | 是 | 优惠券类型：member_monthly（会员月券） |
| coupon_name | string | 是 | 优惠券名称 |
| face_value | number | 是 | 面额 |
| threshold_amount | number | 是 | 使用门槛 |
| valid_start_time | datetime | 是 | 有效期开始 |
| valid_end_time | datetime | 是 | 有效期结束 |
| issue_batch | number | 是 | 发放批次（1-12） |
| status | string | 是 | 状态：unused（未使用）/ used（已使用）/ expired（已过期） |

#### 业务定义
- **分期优惠券**：按月分期发放的会员专属优惠券
- **发放批次**：第 1 期为购买时发放，第 2-12 期为每月发放
- **优惠券叠加**：多张优惠券是否可以同时使用（待确认）

#### 交互说明
- 会员中心展示"我的优惠券"入口，显示可用优惠券数量
- 优惠券列表按发放批次展示，显示有效期和使用状态
- 购物车/结算页自动匹配可用优惠券，默认选择最优组合
- 优惠券即将过期时（3 天内）推送提醒通知

#### 异常处理
- **优惠券过期**：过期后无法使用，不补发
- **优惠券未到账**：联系客服核实发放记录
- **使用门槛不满足**：提示"订单金额未达到优惠券使用门槛"
