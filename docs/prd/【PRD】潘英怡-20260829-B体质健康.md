## 3. 需求概述

### 背景

学生体测数据通常分散在不同项目和测试批次中，体育教师需要分别查看成绩后再人工判断学生的能力优势、薄弱环节和阶段变化，分析效率较低，也不便于向学生说明结果。

### 核心需求

B 体质健康当前只包含“学生分析”一个功能。该功能在同一页面集中展示学生身份与身体基础信息、五项关键体测指标、五维能力画像、核心诊断结论、30m 短跑趋势和跳跃能力变化，并提供返回列表和刷新操作。

### 预期效果

体育教师进入学生分析页面后，可以快速确认学生当前状态，理解各项测试结果及其能力结构，识别主要优势和待提升环节，并通过历史趋势观察阶段变化。

## 4. 需求背景与目标

### 4.1 当前业务目标

1. 在一个页面中完整呈现单个学生的体质与运动能力分析结果。
2. 将单项测试成绩转化为直观的能力画像和文字诊断。
3. 通过多次测试趋势帮助教师判断学生的阶段变化。

### 4.2 用户角色

| 用户角色 | 核心诉求 |
|---|---|
| 体育教师 | 快速理解学生的体测表现、优势和待提升方向 |
| 校队教练 | 查看学生速度、爆发力、稳定性和恢复状态 |
| 学校管理者 | 在授权数据域内查看学生个人分析结果 |

## 7. 功能详细说明

### 7.1 学生分析

**功能定位：**

学生分析是面向单个学生的体质与运动能力综合展示页面，用于把学生档案、当前测试结果、能力结构、分析结论和历史变化集中呈现给体育教师。

**页面展示内容：**

| 页面区域 | 已实现内容 | 业务作用 |
|---|---|---|
| 页面标题 | 展示“学生分析”、所属学校、年级和班级 | 明确当前页面及分析对象范围 |
| 学生档案 | 展示姓名、学号、性别、状态、最近测试时间、年龄、身高和体重 | 确认学生身份及测试背景 |
| 关键指标 | 展示能力得分、30m 总成绩、纵跳高度、立定跳远和 BFI 疲劳度 | 快速了解当前主要体测结果 |
| 能力画像 | 雷达图展示速度、爆发力、协调性、稳定性和恢复力 | 判断学生能力结构和相对短板 |
| 核心诊断 | 展示主要优势、待提升问题、判断依据、短板、提升潜力、训练原则和复测建议 | 将指标转化为可阅读的分析结论 |
| 30m 短跑趋势 | 折线图展示多次 30m 测试成绩并标注最佳成绩 | 观察速度能力的阶段变化 |
| 跳跃能力变化 | 柱状图对比多次纵跳和立定跳远成绩 | 观察垂直及水平爆发力变化 |

**字段定义：**

| 字段名 | 类型 | 是否必填 | 说明 |
|---|---|---|---|
| 学号 | 文本 | 是 | 学生唯一标识 |
| 姓名 | 文本 | 是 | 当前分析学生 |
| 性别 | 枚举 | 是 | 男或女 |
| 学校/年级/班级 | 文本 | 是 | 学生组织归属 |
| 最近测试时间 | 日期时间 | 是 | 当前分析采用的最近测试时间 |
| 年龄 | 数值 | 是 | 学生年龄 |
| 身高 | 厘米 | 是 | 学生身高 |
| 体重 | 千克 | 是 | 学生体重 |
| 能力得分 | 数值 | 是 | 综合运动能力参考分 |
| 30m 总成绩 | 秒 | 是 | 短距离速度指标 |
| 纵跳高度 | 厘米 | 是 | 垂直爆发力指标 |
| 立定跳远 | 米 | 是 | 水平爆发力指标 |
| BFI 疲劳度 | 0—10 数值 | 是 | 当前疲劳恢复参考 |
| 能力画像 | 五维数值 | 是 | 速度、爆发力、协调性、稳定性、恢复力 |
| 核心诊断 | 文本 | 是 | 当前优势、问题和分析依据 |
| 复测建议 | 天数 | 是 | 建议下一次复测时间 |
| 历史成绩 | 数值列表 | 否 | 多次短跑、纵跳和立定跳远结果 |

**产品规则：**

1. 页面必须明确展示当前学生身份和最近测试时间。
2. 状态标签根据当前疲劳指标显示“状态良好”“注意”或“高风险”。
3. 短跑成绩按用时越低表现越好解释；纵跳、立定跳远按数值越高表现越好解释。
4. 能力画像和核心诊断必须能够追溯到页面展示的测试指标。
5. 核心诊断属于体育训练分析，不构成医疗诊断、伤病确认或治疗建议。
6. 历史有效测试少于两次时，不形成趋势判断，只展示已有成绩并提示数据不足。

**交互说明：**

- 点击“返回列表”返回学生信息列表。
- 点击“刷新”重新加载当前学生的分析数据，并显示刷新反馈。
- 图表支持查看各测试序次的具体成绩。

**异常处理：**

- 学生不存在：提示未找到学生，并返回学生列表。
- 测试数据缺失：对应指标显示“暂无数据”，不得使用默认成绩补齐。
- 能力维度不完整：能力画像标明数据不足，不形成完整诊断。
- 历史测试不足：不绘制趋势结论。
- 无查看权限：不展示学生个人信息和健康相关指标。

## 9. 验收标准

1. 用户可从学生列表进入指定学生的学生分析页面。
2. 页面能够展示学生档案和五项关键体测指标。
3. 页面能够展示五维能力画像及核心诊断结论。
4. 页面能够展示 30m 短跑趋势和跳跃能力变化。
5. 返回列表和刷新操作可正常使用。
6. 数据缺失时显示明确空状态，不生成虚假分析结果。
7. 页面明确说明当前内容为体育训练分析和演示数据。
