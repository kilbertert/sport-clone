## 3. 需求概述

### 背景

常规体测结果通常以单项成绩或静态表格呈现，体育教师需要自行判断学生的优势、短板、风险和训练方向。由于学生基础信息、测试成绩、能力结构、历史趋势和训练建议缺少统一视图，个体分析过程耗时，且难以形成连续、可复查的培养记录。

### 核心需求

当前 B 体质健康仅描述已实现的“学生分析”功能。系统将学生档案、五项关键指标、能力画像、核心诊断、成绩趋势和四周运动处方集中在一个页面中，并提供数据刷新、返回列表和加入训练处方等操作，使教师能够从一次体测结果快速形成个体化体育训练参考。

### 预期效果

体育教师进入学生详情后，可在单页内了解学生当前身体与运动能力状态，识别主要优势和待提升环节，查看多次测试变化，并将诊断建议衔接到训练处方流程，减少跨页面查找和人工整理成本。

## 4. 需求背景与目标

### 4.1 当前业务目标

1. 建立学生个人体质与运动能力的统一分析档案。
2. 将单项测试成绩转化为速度、爆发力、协调性、稳定性和恢复力等能力画像。
3. 结合风险与成绩形成可解释的核心诊断结论。
4. 展示阶段变化，并提供可进入训练处方流程的个体训练建议。

### 4.2 用户角色

| 用户角色 | 核心诉求 |
|---|---|
| 体育教师 | 快速理解学生优势、短板和训练方向 |
| 校队教练 | 判断学生运动潜力、训练适应和风险状态 |
| 学校管理者 | 查看授权数据域内学生的个人分析结果 |
| 学生及家长 | 在教师解释下了解个人成长变化和训练建议 |

## 7. 功能详细说明

### 7.1 学生基础档案

**功能定位：** 确认当前分析对象和最近一次测试背景，避免不同学生或不同批次数据混淆。

**当前能力：**

1. 展示学生姓名、头像首字、学号和性别。
2. 根据疲劳情况显示“状态良好”“注意”或“高风险”标签。
3. 展示所属学校、年级、班级和最近测试时间。
4. 展示年龄、身高和体重等身体基础信息。
5. 提供“返回列表”和“刷新”操作。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 学号 | 文本 | 是 | 学生唯一标识 |
| 姓名 | 文本 | 是 | 当前分析对象 |
| 性别 | 枚举 | 是 | 学生性别 |
| 学校/年级/班级 | 文本 | 是 | 学生组织归属 |
| 最近测试时间 | 日期时间 | 是 | 当前分析数据的最近来源时间 |
| 年龄/身高/体重 | 数值 | 是 | 身体基础信息 |
| 状态标签 | 枚举 | 是 | 状态良好、注意或高风险 |

**交互说明：** 点击“返回列表”返回学生信息页；点击“刷新”重新加载当前学生分析结果并显示操作反馈。

### 7.2 关键体测指标

**功能定位：** 用一组核心数字概括学生当前运动表现和疲劳状态。

**当前能力：**

1. **能力得分：** 展示综合潜力分及“良好”等级提示。
2. **30m 总成绩：** 展示短跑成绩及同年级位置说明。
3. **纵跳高度：** 展示下肢快速伸缩复合能力表现。
4. **立定跳远：** 展示水平爆发力成绩和评分提示。
5. **BFI 疲劳度：** 以 0—10 数值及颜色显示当前疲劳程度。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 能力得分 | 数值 | 是 | 综合潜力参考分 |
| 30m 成绩 | 秒 | 是 | 速度能力指标 |
| 纵跳高度 | 厘米 | 是 | 垂直爆发力指标 |
| 立定跳远 | 米 | 是 | 水平爆发力指标 |
| BFI 疲劳度 | 0—10 数值 | 是 | 疲劳恢复参考指标 |

**业务规则：** 单项成绩与提示用于体育教学和训练参考，不得仅依据单次结果作出长期能力结论。

### 7.3 能力画像

**功能定位：** 将分散的测试指标转化为便于教师理解的多维能力结构。

**当前能力：** 使用雷达图同时展示速度、爆发力、协调性、稳定性和恢复力，并在标题区域显示综合潜力分。

| 能力维度 | 当前含义 |
|---|---|
| 速度 | 短距离启动与加速表现 |
| 爆发力 | 纵跳和立定跳远等快速发力表现 |
| 协调性 | 多动作配合和身体控制表现 |
| 稳定性 | 左右侧对称及落地控制参考 |
| 恢复力 | 结合疲劳度形成的恢复状态参考 |

**页面输出：** 一张五维能力雷达图，用于识别突出能力和相对薄弱维度。

**异常处理：** 任一维度缺少有效来源时应显示数据不足，不应使用默认高分补齐画像。

### 7.4 核心诊断结论

**功能定位：** 将指标和能力画像转化为一段可以直接阅读的分析结论。

**当前能力：**

1. 展示主要优势，例如启动加速表现突出。
2. 指出待提升问题，例如落地稳定性或弱侧离心控制不足。
3. 引用左右腿力量差异等指标解释判断依据。
4. 展示短板、提升潜力和训练原则三个结构化结论。
5. 给出建议复测周期，当前演示页面为 14 天。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 核心结论 | 文本 | 是 | 当前优势和主要问题 |
| 判断依据 | 文本/数值 | 是 | 支撑结论的测试指标 |
| 主要短板 | 文本 | 是 | 优先改善方向 |
| 提升潜力 | 枚举 | 是 | 当前提升空间判断 |
| 训练原则 | 文本 | 是 | 负荷与动作执行原则 |
| 建议复测周期 | 天数 | 是 | 下一次复测建议 |

**业务边界：** 核心诊断属于运动能力与体育训练分析，不构成医疗诊断、伤病确认或治疗意见。

### 7.5 成长趋势

**功能定位：** 通过多次测试结果观察学生阶段变化，避免只依据单次成绩判断。

**当前能力：**

1. 使用折线图展示四次 30m 短跑成绩变化，并标注当前最佳成绩。
2. 使用分组柱状图展示四次纵跳和立定跳远变化。
3. 图表支持悬停查看具体测试值。
4. 短跑成绩按“用时越低越好”解释，跳跃成绩按“数值越高越好”解释。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 测试序次 | 文本 | 是 | 第 1 次至第 4 次 |
| 短跑成绩 | 秒 | 否 | 30m 测试结果 |
| 纵跳成绩 | 厘米 | 否 | 纵跳测试结果 |
| 立定跳远成绩 | 米 | 否 | 立定跳远测试结果 |

**异常处理：** 少于两次有效测试时不绘制趋势结论，只展示现有成绩并提示样本不足。

### 7.6 运动处方

**功能定位：** 将学生诊断结果转化为可执行的四周训练建议，并衔接训练处方管理。

**当前能力：**

1. 展示动态活动与跑步技术练习等热身要求。
2. 展示弱侧单腿蹲、低栏连续跳、10m 加速跑等训练动作。
3. 展示建议组数、组间休息和恢复要求。
4. 展示臀中肌与小腿后侧拉伸等放松要求。
5. 点击“加入训练处方”后创建当前学生的处方草稿并进入训练处方页面。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 热身要求 | 文本 | 是 | 训练前准备内容 |
| 训练动作 | 文本列表 | 是 | 当前阶段建议动作 |
| 组数与间歇 | 文本 | 是 | 训练量和恢复间隔 |
| 放松要求 | 文本 | 是 | 训练后恢复内容 |
| 处方周期 | 文本 | 是 | 当前建议为四周 |

**业务规则：** 处方为根据当前演示诊断生成的训练建议草稿，正式执行前需由体育教师或教练确认。

**异常处理：** 学生处于高风险或数据不完整状态时，应优先复核，不应直接生成高负荷训练安排。

## 9. 验收标准

1. 用户可从学生列表进入指定学生分析页，并能返回列表。
2. 页面能够展示学生基础档案、五项关键指标和状态标签。
3. 页面能够展示五维能力画像和结构化核心诊断。
4. 页面能够展示短跑、纵跳和立定跳远的多次测试变化。
5. 页面能够展示热身、动作、组数间歇和放松建议。
6. 点击“加入训练处方”可进入训练处方流程并获得成功反馈。
7. 所有指标明确为演示数据；诊断和处方明确为体育训练参考。
