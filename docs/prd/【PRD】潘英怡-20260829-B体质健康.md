## 3. 需求概述

### 背景

学校体质健康管理通常包含群体数据汇总、异常风险发现、学生个体分析和周期趋势评估。若这些信息分散在不同表格或单次测试报告中，管理者难以及时识别重点人群，教师也难以将测试结果转化为具体干预动作。

### 核心需求

系统围绕“区域总览—风险发现—个体诊断—趋势研究”形成 B 体质健康业务链路，通过精准体育驾驶舱、风险管理、学生分析和科研分析四个页面展示当前已完成能力，并支持筛选、建议生成、数据导出和研究项目管理。

### 预期效果

区域管理者和学校体育教师能够快速掌握整体达标水平、定位风险学生、查看个人能力短板，并通过周期趋势判断干预效果，为分层教学、训练处方和管理决策提供数据依据。

## 4. 需求背景与目标

### 4.1 当前业务目标

1. 提供区域与学校体质健康总览，集中呈现覆盖率、达标率和核心卡点。
2. 识别疲劳、不对称和落地稳定等风险，为复核与干预提供名单。
3. 形成学生个人运动能力诊断，关联风险、成绩趋势和训练建议。
4. 支持体质变化趋势与年级对比，为科研评估和管理复盘提供材料。

### 4.2 用户角色

| 用户角色 | 核心诉求 |
|---|---|
| 区域教育管理者 | 查看区域整体表现、学校差异和优先管理事项 |
| 学校管理者 | 定位本校年级短板与重点风险学生 |
| 体育教师 | 查看个体诊断并形成复测或训练建议 |
| 教研人员 | 观察周期趋势、导出数据并管理研究课题 |

## 6. 业务流程

```text
体测数据汇总
  → 区域/学校体质总览
  → 识别风险与年级短板
  → 查看学生个体分析
  → 生成复测或训练建议
  → 通过科研趋势评估阶段变化
```

## 7. 功能详细说明

### 7.1 精准体育系统

**功能定位：** 作为体质健康管理驾驶舱，集中展示整体指标、重点风险和管理优先级。

**当前能力：**

1. **统一筛选与总览指标：** 支持按学校、年级切换数据范围，展示受伤风险人数、田径与网球人才储备、核心卡点年级、数据覆盖率，并支持导出管理简报。
2. **受伤风险预警：** 汇总左右腿不对称、疲劳恢复不足、落地稳定风险三类问题；支持高、中风险切换，并展示学生、班级、风险值与建议动作。
3. **专项人才储备：** 展示田径队、网球队人才规模、潜力排行和专项标签，使管理者同时看到健康风险与可培养资源。
4. **区域与项目对比：** 展示学校排名、30m 短跑、纵跳、立定跳远、柔韧性等项目达标率，定位学校和项目差异。
5. **群体趋势分析：** 通过年级达标趋势、男女生比例和年级核心卡点表，呈现样本量、达标率、影响人数及改善状态。
6. **管理决策提示：** 将发现的问题整理为“立即、本周、规划”三级动作，支持按年级生成专项干预建议和校级报告。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 学校 | 枚举 | 是 | 当前数据范围 |
| 年级 | 枚举 | 是 | 当前年级范围 |
| 风险人数 | 数值 | 是 | 当前口径下待干预人数 |
| 数据覆盖率 | 百分比 | 是 | 已采集数据覆盖情况 |
| 管理建议 | 文本 | 是 | 立即、本周、规划三级建议 |

**页面输出：** 区域/学校体质概览、重点风险名单、专项人才储备、年级短板及分级管理建议。

**交互说明：**

- 学校和年级筛选统一影响页面指标口径。
- 风险分段按钮切换当前风险名单。
- “生成建议”形成对应年级的专项干预提示。
- “导出管理简报”和“生成校级报告”提供汇报材料出口。

**异常处理：** 筛选无匹配数据时保留模块结构并显示“暂无数据”，不得沿用其他范围的数据。

### 7.2 风险管理

**功能定位：** 从疲劳恢复和左右腿不对称两个维度筛查需要重点复核的学生。

**当前能力：**

1. **风险总览：** 汇总当前数据范围内的风险人数及高风险数量，形成管理入口。
2. **疲劳风险识别：** 使用 BFI 疲劳值呈现学生恢复状态，支持定位训练负荷或恢复不足对象。
3. **身体不对称识别：** 展示左右腿不对称率，辅助发现弱侧力量、动作控制和稳定性问题。
4. **风险名单管理：** 列出学生、学校、年级、疲劳值、不对称率和风险等级，支持学校筛选及名单刷新。
5. **干预参考：** 依据风险表现提供降低训练量、增加恢复、弱侧训练或动作纠正等方向性建议。

**业务规则：** 风险等级用于体育训练管理和复测排序，不构成疾病判断、医学诊断或治疗建议。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| BFI 疲劳值 | 数值 | 是 | 疲劳风险参考指标 |
| 不对称率 | 百分比 | 是 | 左右侧能力差异 |
| 风险等级 | 枚举 | 是 | 高、中、低风险 |
| 建议动作 | 文本 | 是 | 复核、恢复或动作纠正建议 |

**页面输出：** 风险学生名单、风险指标依据和建议干预方向。

**交互说明：** 切换学校后刷新对应名单；点击刷新重新加载当前范围结果；用户可从风险名单进一步进入学生个人分析。

**异常处理：** 缺少有效测试数据时不计算风险结论；单项缺失时需明确显示缺失状态，不以默认值替代。

### 7.3 学生分析

**功能定位：** 将学生基础信息、测试表现、风险和训练建议汇总为个人分析档案。

**当前能力：**

1. **学生基础档案：** 展示学生姓名、学号、性别、年龄、身高、体重、学校、年级班级和最近测试时间。
2. **关键测试结果：** 展示能力总分、30m 短跑、纵跳、立定跳远和 BFI 疲劳度，并给出同年级位置或状态提示。
3. **能力画像：** 使用雷达图呈现速度、爆发力、协调性、稳定性和恢复力，帮助教师理解能力结构，而非只看单项成绩。
4. **核心诊断结论：** 结合测试结果说明优势、待提升环节、训练原则和建议复测周期。
5. **成长趋势：** 展示多次短跑成绩及纵跳、立定跳远变化，观察阶段进步或波动。
6. **运动处方：** 根据当前诊断展示热身、训练动作、组数间歇和放松要求，并支持加入训练处方。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 学生标识 | 文本 | 是 | 学生唯一标识 |
| 测试成绩 | 数值 | 是 | 各测试项目结果 |
| 能力评分 | 数值 | 是 | 速度、爆发等维度表现 |
| 训练建议 | 文本 | 是 | 当前诊断对应的训练方向 |

**页面输出：** 学生个人能力档案、诊断摘要、趋势结果和四周训练建议。

**交互说明：** 支持返回学生列表、刷新分析数据，并将当前建议带入训练处方管理流程。

**异常处理：** 测试次数不足时仅展示已有结果并提示趋势样本不足；个人信息和健康相关指标仅向授权数据域用户展示。

### 7.4 科研分析

**功能定位：** 对体质健康数据进行周期追踪、年级比较和研究项目管理。

**当前能力：**

1. **科研指标总览：** 展示体质达标率、优良率、覆盖样本、跟踪周期和进行中课题数量。
2. **成长趋势分析：** 以周期折线展示达标率与优良率变化，支持周期、班级、年级等比较口径选择。
3. **年级效果比较：** 对比各年级达标率和优良率，观察干预前后或不同群体的表现差异。
4. **核心短板分布：** 汇总速度耐力、下肢爆发、柔韧性和协调性等维度，标识优先干预方向。
5. **课题全过程管理：** 展示课题编号、名称、负责人、样本量、阶段、截止时间和完成进度，并支持新建课题档案。
6. **科研数据出口：** 支持导出周期、达标率、优良率、短跑与纵跳等结构化数据，供后续统计和材料编制。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 达标率 | 百分比 | 是 | 当前周期体质达标比例 |
| 优良率 | 百分比 | 是 | 当前周期优良比例 |
| 跟踪周期 | 数值 | 是 | 已纳入比较的周期数 |
| 研究项目 | 对象 | 否 | 课题名称、负责人、样本和进度 |

**页面输出：** 学校体质研究概览、周期趋势、年级比较、短板排序和课题进度。

**交互说明：** 用户可切换比较口径、导出科研数据和新建课题；创建课题时填写名称、负责人、样本量和计划结题日期。

**异常处理：** 周期或样本不足时不得形成确定性效果结论；导出数据需保持当前筛选口径和指标定义一致。

## 9. 验收标准

1. 四个页面可从生产环境正常访问，页面核心内容与截图一致。
2. 精准体育系统能够展示总体指标、风险名单、趋势和管理建议。
3. 风险名单可表达疲劳与不对称两个风险维度。
4. 学生分析能够从个体数据进入训练处方业务流程。
5. 科研分析能够展示周期趋势并支持数据导出和课题创建。
6. 所有演示指标均明确标注为演示数据，不作为真实业务结论。
