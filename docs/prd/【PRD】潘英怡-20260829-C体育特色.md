## 3. 需求概述

### 背景

学校建设特色田径队，需要同时解决“选谁、适合什么项目、怎样训练、如何备赛”四类问题。仅依赖教师经验时，候选依据、项目适配、周期训练与赛事计划容易分散，难以形成连续、可说明的培养档案。

### 核心需求

当前 C 体育特色以“特色田径队”为唯一已实现功能，通过 AI 选材、冠军训练体系、竞技训练、赛事备战四个子页面，完成候选筛选、项目适配、运动员培养和比赛准备的业务展示，并提供选材报告、适配报告、专项计划和备战计划等操作入口。

### 预期效果

校队教练和学校管理者能够从统一页面了解运动员规模、候选人才、训练安排、伤病风险和赛事任务，使特色田径队从一次性选拔升级为覆盖选材、培养和备赛的连续管理流程。

## 4. 需求背景与目标

### 4.1 当前业务目标

1. 综合运动成绩、专项潜力和风险信息形成候选名单。
2. 明确学生适合的主项、当前阶段、预期目标和优先训练路径。
3. 按赛季阶段组织基础储备、专项强化、赛前调整和赛后恢复。
4. 汇总备战赛事、参赛人数、时间节点和备战阶段。

### 4.2 用户角色

| 用户角色 | 核心诉求 |
|---|---|
| 学校管理者 | 掌握校队规模、高潜候选、训练频次、赛事和风险情况 |
| 校队教练 | 完成候选筛选、项目适配、周期训练与赛事备战 |
| 体育教师 | 提供学生测试表现、训练适应和风险复测信息 |
| 运动员 | 获得明确的专项方向、阶段目标和培养路径 |

## 6. 业务流程

```text
学生运动能力数据
  → AI 选材形成候选名单并确认入队
  → 冠军训练体系确定适合项目和阶段目标
  → 竞技训练安排年度周期与周训练模板
  → 赛事备战管理比赛时间、阶段和参赛人员
  → 比赛及复测结果用于后续培养调整
```

## 7. 功能详细说明

### 7.1 AI 选材

**功能定位：** 综合速度、爆发力、风险与专项潜力，形成可操作的校队候选名单。

**页面组成与当前能力：**

1. **校队指标总览：** 展示校队运动员、高潜候选、备战赛事、本周训练和伤病高风险人数。
2. **候选名单：** 展示学生、年级、建议专项、潜力分、30m 成绩和风险等级。
3. **专项筛选：** 支持全部项目、短跑、纵跳、跳远、跳跃等项目过滤。
4. **入队管理：** 支持“选入校队”和“移出校队”，操作后即时更新候选状态与校队人数。
5. **重点运动员档案：** 展示速度潜力、爆发力、训练适应、伤病风险及主副项培养建议。
6. **报告与批次：** 支持导出选材报告，并提供新建选拔批次入口。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 学生/学号 | 文本 | 是 | 候选学生身份 |
| 建议专项 | 枚举 | 是 | 短跑、纵跳、跳远等推荐方向 |
| 潜力分 | 数值 | 是 | 综合候选评价 |
| 30m 成绩 | 数值 | 是 | 速度能力参考 |
| 风险等级 | 枚举 | 是 | 当前训练风险参考 |
| 入队状态 | 布尔/枚举 | 是 | 候选是否进入校队 |

**页面输出：** 校队候选名单、重点运动员档案和可导出的选材报告。

**异常处理：** 缺少有效测试数据时不得进入候选排序；高风险学生可以保留观察，但需明确提示复核后再安排训练。

### 7.2 冠军训练体系

**功能定位：** 回答“学生适合什么项目、当前处于什么水平、阶段目标是什么、优先练什么”。

**页面组成与当前能力：**

1. **AI 项目适配报告：** 展示学生适合项目、适配度、当前情况、预期目标和培养阶段。
2. **搜索与选择：** 支持按学生姓名、学号或项目搜索，并点击列表切换右侧目标画像。
3. **目标画像：** 展示适配依据、当前表现、目标成绩和基础提升/专项观察/可进入专项等阶段状态。
4. **基准趋势对比：** 将学生当前路径、阶段目标与速度基准进行趋势对照，用于说明差距和培养方向。
5. **训练路径：** 给出起跑、加速、最高速度、力量或恢复等优先训练路径。
6. **专项计划：** 支持为当前学生生成对应项目的专项训练计划，并可导出项目适配报告。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 适合项目 | 文本/枚举 | 是 | 推荐主项或培养方向 |
| 适配度 | 数值 | 是 | 项目匹配参考分 |
| 当前情况 | 文本 | 是 | 当前成绩或能力阶段 |
| 预期目标 | 文本 | 是 | 阶段培养目标 |
| 培养阶段 | 枚举 | 是 | 基础提升、专项观察、可进入专项 |
| 优先训练路径 | 文本 | 是 | 建议训练顺序 |

**业务边界：** “冠军训练体系”表示对标优秀训练逻辑和阶段目标，不代表系统承诺学生达到冠军成绩。

### 7.3 竞技训练

**功能定位：** 将运动员培养安排到年度训练周期，明确不同阶段的训练重点。

**页面组成与当前能力：**

1. **年度周期化训练：** 按基础储备期、专项强化期、赛前调整期、赛后恢复期组织赛季。
2. **阶段时间与进度：** 每个阶段展示月份或时间范围、当前进度和训练主题。
3. **训练重点：** 覆盖力量基础、动作技术、一般耐力、启动加速、最高速度、专项力量、减量提质、心理准备和主动恢复。
4. **训练周模板：** 提供起跑技术、最高速度、专项力量和主动恢复的周频次示例，并支持应用模板。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 训练阶段 | 枚举 | 是 | 年度周期阶段 |
| 时间范围 | 文本 | 是 | 阶段计划时间 |
| 完成进度 | 百分比 | 是 | 当前执行进度 |
| 训练重点 | 文本 | 是 | 阶段训练主题 |
| 周模板 | 对象 | 是 | 每类训练的周频次安排 |

**页面输出：** 赛季周期视图和可应用的训练周模板。

**异常处理：** 运动员存在高风险或伤病状态时，训练模板不得直接作为执行结论，应由教练调整负荷并完成复核。

### 7.4 赛事备战

**功能定位：** 汇总近期赛事及备战状态，为教练安排参赛人员和训练节奏提供入口。

**页面组成与当前能力：**

1. **赛事列表：** 以卡片展示赛事名称、日期、距离比赛天数和当前状态。
2. **备战阶段：** 标识专项强化、赛前调整或待启动等阶段。
3. **参赛规模：** 展示每场赛事拟参赛运动员数量。
4. **备战计划入口：** 支持打开对应赛事的备战计划，并反馈操作结果。
5. **全局联动指标：** 页面顶部同步展示备战赛事数量、本周训练次数和伤病高风险人数。

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| 赛事名称 | 文本 | 是 | 目标比赛 |
| 比赛日期 | 日期 | 是 | 赛事时间 |
| 距离天数 | 数值 | 是 | 当前距比赛天数 |
| 备战阶段 | 枚举 | 是 | 当前训练准备阶段 |
| 参赛运动员 | 数值 | 是 | 计划参赛人数 |
| 赛事状态 | 枚举 | 是 | 备战中或未开始 |

**页面输出：** 赛事任务列表及各赛事备战计划入口。

**异常处理：** 日期临近但未进入备战阶段时需提示管理者；高风险运动员是否参赛应由教练复核，不由系统自动决定。

## 9. 验收标准

1. 特色田径队页面可从生产环境正常访问，四个子页面可正常切换。
2. AI 选材能够筛选候选、展示运动员档案并切换入队状态。
3. 冠军训练体系能够搜索学生、切换目标画像并生成专项计划。
4. 竞技训练能够展示年度四阶段训练和训练周模板。
5. 赛事备战能够展示赛事、时间、阶段、参赛人数和备战计划入口。
6. 所有选材、适配与训练结果均标明为演示数据和辅助决策，不形成自动录取、医疗或成绩承诺。
